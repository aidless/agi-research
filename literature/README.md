# literature/

## 这里的文件是什么

**两个目的**：
1. **Codex 写的论文综述**（`*.md`，无子目录）— 我把论文的核心论点、创新点、未解决的问题、与 AGI 主题的关系整理出来
2. **你自己写的 paper 阅读笔记**（`00_daily/your_papers_you_read/`）— 强制你用自己的话写 1-3 句话，这是不能外包的

## 使用约定

| 文件类型 | 命名 | 谁写 |
|---|---|---|
| 系统综述 | `literature/<topic>_review.md` | Codex |
| 单篇 paper 笔记 | `literature/papers/<year>_<author>_<short>.md` | Codex |
| 你的个人 reading log | `00_daily/your_papers_you_read/<date>_<paper>.md` | **你** |
