## 2. File preparation (PI must do)

arXiv accepts a single .tar.gz or .zip with the source files. The
submission should include:

- [ ] `thesis.tex` (LaTeX) OR `thesis.md` (Markdown, auto-converted).
      LaTeX preferred for better typesetting.
- [ ] All figures (none currently in thesis; thesis is text-only).
- [ ] `biblio.bib` (BibTeX) if converting to LaTeX. References are
      inline in Markdown currently.
- [ ] `00README.XXX` (arXiv convention): brief README. Current
      `README.md` works.
- [ ] **OPTIONAL**: include the Y1 paper v3.8 as a companion
      (`releases/y1-paper-v3.7/paper.md`).
- [ ] **OPTIONAL**: include the 9-hypothesis framework as a
      supplementary document.

## 3. PDF generation options

If PI wants a PDF for arXiv (arXiv accepts both source + PDF, but
the PDF must be generated from the source):

- [ ] **Option A**: pandoc
  `pandoc thesis.md -o thesis.pdf --bibliography=biblio.bib --citeproc`
  (requires LaTeX install + pandoc-citeproc)
- [ ] **Option B**: manuscript-tools / quarto
  `quarto render thesis.md --to pdf`
- [ ] **Option C**: arXiv auto-converts the Markdown source. Less
      control over formatting but easier.
- [ ] **Already have**: `thesis.pdf` (188 KB) was generated by an
      earlier session; can be re-uploaded as-is if PI prefers.

- [ ] **Every positive claim has a stated limitation** (or

## 7. Risk assessment

What could go wrong:

- **Single-author attribution**: arXiv may require a real
  institutional affiliation. PI to verify.
- **Long title**: "Archimedes: A 5-Year Research Program Toward a
  Self-Improving AGI Substrate" is 14 words; some venues have
  shorter title limits. Consider a shortened title.
- **No external replication**: until another lab replicates the H1
  + Y1.3 results, the thesis is single-source.
- **Pre-registration timeline**: the thesis discloses in §6 that
  not all experiments were pre-registered in the traditional sense.
