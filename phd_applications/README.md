## Customization Guide

### Statement of Purpose

For each program:
- Replace §2 ("Why This Program?") with specific lab/advisor names.
- Reference recent papers from the program''s faculty.
- Adjust §3 (background) to fit the program''s emphasis.
- §5 (career goals) usually doesn''t change.

### CV

- Fill in undergraduate institution, GPA, graduation year.
- Add any awards/honors.
- Add any publications (currently none; planned Y2).
- Add any service activities.

### Writing Sample

- Target 8-10 pages (most common limit).
- Focus on H1 ablation (§4.1) + Slot-Monitor (§4.2).
- Include abstract + §1 + §3 (method) + §4 (results).
- Include reproducibility link to GitHub.
