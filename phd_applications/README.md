The v1.0 template has been preserved as the generic top-level template.
v2.0 (the per-program variants) supersedes v1.0 for actual submissions.

What v2.0 adds:

- **6 program-specific variants** under `programs/`. Each ~700 words.
- **Program-specific research-summary framing**: Section 1 rewritten to
  reflect the 8-pre-reg-tests-0-supported finding and the Y1 paper v3.7

- Does not verify recent paper references (PI should double-check).
- Does not adjust for program-specific submission portal rules.
- Does not translate to Chinese if the user wants it.

## Customization Guide

### Statement of Purpose

For each program:

- **Add 1-2 specific lab / advisor names** in Section 2 (PI action).
- **Reference 1 recent paper from each target program** that connects
  to Archimedes (PI action).
- **Adjust Section 3** to emphasize the user's strongest background
  areas per program (PI action).
- **For research-scientist applications** (DeepMind, Anthropic):
  remove "PhD years" references; convert tone from "graduate
  admissions" to "research statement" (PI action).

### CV

- Fill in undergraduate institution, GPA, graduation year.
- Add any awards/honors.
- Add any publications (currently none; planned Y2).
- Add any service activities.

### Writing Sample

- Target 8-10 pages (most common limit).
- Focus on H1 ablation (Section 4.1) + Slot-Monitor (Section 4.2).
- Include abstract + Section 1 + Section 3 (method) + Section 4 (results).
- Include reproducibility link to GitHub.
