## What changed from v1.0 template

All six variants are based on the v1.0 template (`../statement_of_purpose.md`),
but each customizes:

1. **Header block** -- adds the program name, type (PhD vs research
   scientist), and customization date.
2. **Section 1 (Research Summary)** -- updated to reflect the latest
   Archimedes state (8 pre-reg H tests, 0 supported; Y1 paper v3.7; +
   50 LunarLander n=15 p<0.001 headline; 9-hypothesis framework).
3. **Section 2 (Why This Program?)** -- fully rewritten per program
   to name research areas, intellectual neighbours, and specific
   directions.
4. **Section 3 (Background)** -- reordered bullet points to emphasize
   the most relevant background for each program (e.g. multi-agent
   for CMU/DeepMind; slot attention for Berkeley; governance for
   Anthropic; foundation models for Stanford).

Sections 4 (Philosophy), 5 (Career Goals), 6 (Why Me) are kept close
to the v1.0 wording because they are universal across programs.
