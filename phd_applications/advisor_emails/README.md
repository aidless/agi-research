## What the templates share

Each cold email has the same structure:
1. **Subject line** (specific to the program).
2. **One-paragraph opener**: who I am, what I''m applying for,
   ask (review / consider / conversation).
3. **Brief background**: 7 years independent study + Archimedes
   Project + 1-2 most relevant results.
4. **Why this program / group**: 1 specific recent paper / direction.
5. **What I would like to do**: 3 specific directions.
6. **Attachments note**: SoP + CV + writing sample.
7. **Sign-off**: name, GitHub, project.

## What is NOT shared (program-specific)

- The "Why this group" paragraph names specific recent papers /
  research directions (PI to fill in).
- The "What I would like to do" list is reordered per program
  (e.g., governance for Anthropic, slot attention for Berkeley).
- The tone for industry research-scientist applications
  (DeepMind, Anthropic) is "research collaboration", not
  "graduate application".

## Customization checklist for the PI

For each template, the PI should:

- [ ] **Identify 1-2 specific faculty / research leads** at each
      program. Replace `[LastName]` and `[Research Lead]`.
- [ ] **Reference 1 recent paper** from each target''s research
      group. Replace `[specific recent paper]`.
- [ ] **Customize the "What I would like to do"** list if the PI
      wants to emphasize different directions.
- [ ] **Verify the email address** for each target (use the
      program''s official faculty directory).
- [ ] **Add a brief sign-off line** if the PI wants to mention
      a referral or shared connection.

## Sending the emails

- **Timing**: send in early September 2026 (4-6 weeks before US
  PhD application deadlines).
- **Personalization**: even with templates, each email MUST be
  personalized with the specific faculty member''s name and a
  specific paper. Generic emails are easy to spot and ignored.
- **Follow-up**: if no response in 2 weeks, a polite follow-up
  is acceptable. If still no response, move on.

## Honest boundary

These templates do NOT include any false claims or fabricated
faculty names. The PI must add the specific names. The recent
papers referenced in the templates are placeholders.

The "What I would like to do" lists describe genuinely planned
research directions, not vague aspirations. The Archimedes
Project has produced concrete results in each of the directions
listed.
