# Phase 2.7: 100K PPO Honest Evaluation — verifier-aware gating

> Date: 2026-07-27
> Status: BREAKTHROUGH - PPO works at 100K, gating still negative but smaller
> Author: 刘泽文 (Liu Zewen) + Codex

## 1. Question

What's the actual performance of the verifier-aware gating system
when PPO is given proper training (100K steps) instead of 4K?

## 2. Method

Same `code/phase26_verifier_gating.py` as Phase 2.6 smoke,
but with:
- 100K PPO (vs 4K smoke)
- 200 train episodes (vs 10)
- 5 eval episodes (vs 1)
- 32 history length (vs 4)
- viol_threshold=1 (vs 2 in earlier smoke)
- gate_threshold=0.5

## 3. Results (LunarLander-v3, 100K PPO, 5 episodes)

| metric | value |
|---|---|
| **Ungated PPO mean** | **+145.3** |
| Gated (Monitor+Verifier) mean | +83.5 |
| **Delta** | **-61.8** |
| Gate triggers | monitor=47, verifier=0, both=0, neither=1680 |
| % steps gated | 2.7% |

## 4. Key findings

1. **PPO at 100K works**: mean reward +145.3 (vs -216 at 4K).
   25x more PPO training makes the difference between "agent crashes
   every episode" and "agent lands sometimes".

2. **Gating still hurts but much less**: -61.8 (vs -467 at 4K). At
   proper PPO, the absolute value of the delta is much smaller.

3. **Verifier rarely fires with viol_threshold=1**: 0/1727 steps.
   The agent at 100K PPO doesn't accumulate violations as fast as at
   4K (because it has better control, fewer rule violations).

4. **Monitor is the only gating signal in practice**: 47 monitor
   triggers. These 47 interventions are enough to cause -61.8 delta.

## 5. Interpretation

The Monitor (SlotMonitor, AUROC 0.989 in isolation) is too eager
when used online:
- AUROC 0.989 means it correctly ranks failure vs success states
- But for online gating, the threshold matters: at 0.5, even
  non-failure states sometimes exceed threshold (47 fires over 1727
  steps = 2.7%)
- Each fire over-rules PPO, which on a working PPO is usually
  the wrong choice (PPO action would have been better)

The Monitor is correct in ranking but the threshold is too low
for online use. Need threshold tuning:
- 0.5 -> 47 fires -> -61.8 delta
- 0.7 -> maybe 20 fires -> less interference
- 0.9 -> maybe 5 fires -> minimal interference

## 6. Cumulative AGI roadmap (revised with 100K PPO)

| Phase | 4K PPO | 100K PPO |
|---|---|---|
| 1.5 full integration | -467 | (not yet tested) |

**Lesson**: All previous results at 4K PPO were dominated by
training noise. At 100K PPO, the gating delta is ~10x smaller,
and the architectural effect becomes more visible.

## 7. Y1 follow-up to make gating win

1. **Threshold tuning**: try 0.6, 0.7, 0.8, 0.9
2. **Multi-seed evaluation**: run 5 seeds to average out PPO noise
3. **Larger Q-function**: 256-hidden, more training epochs
4. **Verifier rule learning**: instead of hardcoded rules, learn
   rules from PPO failure data
